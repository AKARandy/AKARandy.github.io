01 / Applied AI

Tanya Sekolah ↗

School Q&A with SQL, retrieval, and tuition estimates.

School information from four government portals, brought into one application covering 2,269 schools. Ask a question in Indonesian or English; get structured data, relevant school profiles, or a clearly labeled tuition estimate.

Read the engineering notes

Built: Selenium data collection, SQLite preparation, ChromaDB retrieval with multilingual embeddings, and a CatBoost tuition model, exposed through FastAPI and packaged with Docker.

Reliability: Hand-written LLM routing, guarded read-only SQL, semantic-search fallbacks, and automated tests for data preparation, API behavior, and SQL safeguards.

Scope: Surabaya and Sidoarjo. Tuition predictions are estimates, not exact quotes; recorded fees and model estimates are distinguished in the answer.

02 / ML engineering

Self-Retraining Model Platform ↗

A local experiment in automated model retraining.

A complete model lifecycle running locally in containers: ingestion, training, evaluation, serving, and monitoring. A drift signal starts retraining; an evaluation gate keeps a weaker challenger from replacing the current model.

Read the engineering notes

Built: FastAPI over PostgreSQL, MinIO, and MLflow, with an eight-step Argo training workflow on local Kubernetes. DVC tracks dataset versions; a React dashboard shows runs and monitoring results.

Reliability: Prediction logging, audited writes, conditional promotion, model swaps without API redeployment, and automated checks through GitHub Actions.

Scope: Demonstrated on a local regression workload. Cloud deployment and stronger drift statistics are future improvements, not claimed production capabilities.

  • FastAPI
  • MLflow
  • Argo Workflows
  • Kubernetes
  • PostgreSQL
  • DVC
  • Docker

03 / Data analysis

Lights vs Numbers ↗

What do activity signals say alongside official GDP?

Cleaned and aligned shipping activity, Google Trends, and official GDP series across different time frequencies, then turned the analysis into annotated Plotly charts and a Streamlit dashboard.

Read the analysis notes

Method: Traceable sources, explicit aggregation, and descriptive comparisons. The dashboard separates sample series from live data; night-light and electricity examples are not presented as fully integrated live feeds.

Scope: These comparisons explore patterns, not causal proof or a claim that official GDP is incorrect.

Web scrapers!

The data work starts before the dataset exists.

Dapodikdasmen, Sekolah Kita, and Verval Yayasan collect from separate school portals. Each scraper is built around how its source behaves. Dapodikdasmen gives up school listings district by district with retry logic and batch CSV, Sekolah Kita profiles come down by NPSN code with checkpoint and resume, and Verval Yayasan gets crawled six levels deep with async Python. Together they feed one dataset, which turned into InternProject-SPP_Sekolah, the tuition prediction project, and then tanya-sekolah, the LLM assistant built on top of it.

PDDIKTI is educational too but serves a different purpose, covering universities rather than schools in the national higher education database. Scraped across semesters with a multithreaded Selenium setup.

Another project is LinkedIn jobs, collected with session persistence and configurable pacing.
