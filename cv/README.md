# General CV

`main.tex` contains the editable general CV, covering data analysis, applied AI, and Python development. It supports pdfLaTeX and XeLaTeX/Tectonic.

The website downloads `../assets/CV_Alief_Randiansyah_Pradanaputra.pdf`. That file is the visually reviewed, one-page PDF edition. The LaTeX source contains the same content in an editable layout; its pagination may differ from the PDF edition.

Keep both versions aligned when updating employment, dates, metrics, projects, and contact details. Role-specific CVs should be separate copies rather than replacing this general version.
